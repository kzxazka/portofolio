# azka-porto

Portofolio website built with Next.js, Tailwind CSS, and MDX. This project showcases personal and professional works, with a modern UI and smooth page transitions.

## Features
- Next.js 13 App Router
- Tailwind CSS for styling
- MDX for content management
- Animated page transitions
- Responsive design
- Project showcase with dynamic routing

## Getting Started

1. **Install dependencies**
	```bash
	pnpm install
	```
2. **Run development server**
	```bash
	pnpm dev
	```
	Open [http://localhost:3000](http://localhost:3000) to view the site.

## Folder Structure

- `app/` — Main application pages and components
- `content/` — MDX files for project content
- `lib/` — Utility functions
- `pages/api/` — API routes
- `public/` — Static assets (images, fonts)
- `types/` — TypeScript type definitions
- `util/` — Additional utilities

## Customization
- Add new projects in `content/projects/` as `.mdx` files
- Update site components in `app/components/`
